Hãy triển khai repo này lên tài khoản Cloudflare của tôi bằng Cloudflare Workers Free + D1 + Workers KV (không dùng R2). Đọc AGENTS.md và docs/CLOUDFLARE.vi.md. Dùng nhánh có wrangler.jsonc, Node 24, npm ci, npm test, npm run check và npm run cf:check. Giữ nguyên các migration đã áp dụng.

MCP là Remote MCP Streamable HTTP tại https://<tên-miền-worker>/mcp, OAuth 2.1 với PKCE. Website đăng nhập GitHub; MCP dùng cùng danh tính github:<numeric-id>. Không tin các header oai-authenticated-* từ Internet. Các secret GITHUB_CLIENT_ID/GITHUB_CLIENT_SECRET phải nhập qua Cloudflare Settings hoặc Wrangler secret, không dán vào chat hay Git. PUBLIC_ORIGIN phải là origin HTTPS chính thức. Chỉ người trong GITHUB_ALLOWED_IDS hoặc GITHUB_ALLOWED_LOGINS được dùng dữ liệu.

Chọn Workers → Continue with GitHub, không dùng Pages static. Build command npm run build:cloudflare; deploy command npm run deploy:cloudflare; root /. D1 binding DB, KV FILES_KV cho tệp và KV OAUTH_KV cho đăng nhập. Giới hạn 20 MiB/tệp, hạn mức KV Free dùng chung tài khoản; tệp có thể chờ đồng bộ 60 giây hoặc hơn. Không đặt state/claim/duyệt vào KV. Không tạo R2 bucket. Gói này không gọi model API; mọi AI và tạo ảnh thực hiện trong phiên ChatGPT/Codex qua MCP. Ghi rõ phần chưa kiểm chứng do thiếu quyền Cloudflare/GitHub OAuth thật. Không tự chuyển dữ liệu Sites hoặc ghi đè dữ liệu cũ.

Script deploy tự tìm lại D1/KV đúng tên mặc định trong tài khoản đang xác thực khi cấu hình thiếu ID; giữ nguyên ID đã ghim. Nếu gặp lỗi KV 10014 vì namespace đã tồn tại, dùng script này, không xóa namespace OAuth hay tạo kho tên ngẫu nhiên. Với resource đặt tên riêng, ghim ID đúng trong wrangler.jsonc.
